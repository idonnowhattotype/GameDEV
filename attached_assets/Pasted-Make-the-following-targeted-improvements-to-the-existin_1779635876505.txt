Make the following targeted improvements to the existing Cosmic Cleanup game. Do not break any existing mechanics.
1. Enemy HP colour feedback
When an enemy takes a hit, update its tint permanently based on remaining HP. At full HP: no tint. At 2/3 HP remaining: tint 0xff8888 (light red). At 1/3 HP remaining: tint 0xff2200 (bright red). At 1 HP remaining: rapidly flicker between 0xff0000 and 0xffffff every 3 frames. Clear the flicker and use 0xff0000 solid when the enemy is destroyed. Apply this to both regular satellites and the boss.
2. Bomber charge-up warning
When a bomber's drop timer reaches 1.5 seconds remaining, start a charge-up visual: draw a growing white-yellow circle around the bomber that expands from radius 10 to radius 26 over 1.5 seconds, alpha 0.6, using the existing _fxGfx graphics layer. When the bomb drops, flash the bomber white for 4 frames. This gives the player a clear 1.5-second warning.
3. Fix score pop-up stacking
When spawning a "+10" or any score pop-up text, add a random horizontal offset of ±25px and a random vertical starting offset of ±10px to the spawn position. This scatters simultaneous pop-ups so they do not perfectly overlap. Cap simultaneous pop-up objects at 8 — if 8 are already active, skip spawning a new one rather than adding to the pile.
4. Verify and fix the boss HP bar
Check that _bossHpBarBg, _bossHpBarFg, and _bossHpLbl are created and added to the scene in _spawnBoss(). The bar should be 200px wide, 14px tall, centred horizontally at the top of the screen below the HUD (y = 58). Background is dark red #440000. Foreground fills left-to-right in bright red #ff2200 proportional to hp / maxHp. The label reads BOSS in small white text above the bar. Update the bar every frame in _updateBoss(). Make sure setAlpha(1) is called when the boss spawns and setAlpha(0) when it dies.
5. Touch UI fire button visual
Draw the fire button circle on the _touchGfx layer every frame when a touch device is detected (this.sys.game.device.input.touch === true). Fire button: circle outline at _FIRE_BTN position, radius 42, stroke #ff4444, alpha 0.35, with a small filled circle in the centre radius 8, fill #ff4444, alpha 0.5, and the text FIRE in 10px white centred inside it. Dash button: circle outline at _DASH_BTN, radius 30, stroke #ffff44, alpha 0.35, text DASH in 10px white. Only draw these when the game is not paused and intro is complete.
6. Mute button
Add a mute toggle button to the HUD. Position it top-right, after the health hearts, as a small clickable text object showing 🔊 when sound is on and 🔇 when muted. On click: if muting, call AM.stopMusic() and set a flag AM.muted = true. If unmuting, set AM.muted = false and call the appropriate music restart (playMenuMusic or playGameMusic). When AM.muted is true, all _tone() calls and noise buffer calls must return immediately without playing. Add if (this.muted) return; at the top of every sound method in AudioManager. The mute state persists in localStorage under key cosmicCleanup_muted so it is remembered between sessions.
7. Level complete panel slide-in
In LevelCompleteScene, wrap all panel elements in a container. Set the container's initial y to -300. Use this.tweens.add({ targets: container, y: 0, duration: 400, ease: 'Back.easeOut' }) on scene create so the panel bounces into position. If this tween already exists, verify it is actually running — add a console.log('LevelComplete tween started') temporarily to confirm, then remove it.
Do not change level logic, enemy behaviour, scoring, or any other system. Zero console errors after changes.
